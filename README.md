# Road Damage Detection

A deep learning project to detect road damage using CNN and Flask.

## Tech Stack
- Python, Flask, TensorFlow, OpenCV
- HTML, CSS, JavaScript
- Dataset: Kaggle Pothole Dataset (665 images)

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Train model: python train_model.py
3. Run app: python app.py
4. Open: http://localhost:5000
